# calculadora-pontua-o
projeto simples para calcular medias de pontuações
a calculadora permite informar tres pontuações e calcular a media final:

Projeto desenvolvido para praticar programação e conceitos de DevOps.

## Sobre o projeto

A calculadora recebe três pontuações:

- Presença
- Posicionamento
- Ponto Extra

Depois, calcula a média final das pontuações.

## Como executar

Execute o arquivo `calculadora.py` utilizando Python:

```bash
python calculadora.py

Exemplo
=== CALCULADORA DE PONTUAÇÃO ===

Digite a pontuação de Presença (0 a 100): 80
Digite a pontuação de Posicionamento (0 a 100): 70
Digite a pontuação de Ponto Extra (0 a 100): 90

Pontuações cadastradas com sucesso!
Média final: 80.00
